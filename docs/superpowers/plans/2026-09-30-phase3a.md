# Phase 3A Implementation Plan
> For agentic workers: use superpowers:subagent-driven-development with disjoint task ownership, followed by integration and review.
Goal: dynamic classification bank, durable wrong-question state and scalable year selection.
Architecture: registry-derived static inventory plus independent personal state; existing study routes remain source of practice.
Tech Stack: TypeScript/React, Dexie, Vitest, Node build tools, Playwright.
Spec: docs/superpowers/specs/2026-09-30-phase3a-design.md

## Global constraints
No PDF/source/old question edits. Nine blockers unchanged. No Firebase activation/adaptive weighting. Human locked classification never overwritten. No deletion/mutation of existing personal history. User authorizes direct execution after self-review.

## Review focus
- Ineligible/deleted test results cannot linger in wrong state.
- Pending U assessments and duplicate submissions do not create synthetic errors.
- Missing classifications and unavailable topics do not hide production questions.
- Late module loading and navigation preserve URL filters.
- Backup/sync imports and module resets preserve manual dismissal and notes.
