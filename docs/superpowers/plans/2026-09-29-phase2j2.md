# Phase 2J.2 Implementation Plan

> Execute inline with superpowers:executing-plans; one independent final review.

**Goal:** Separate permanent notes, historical attempts and the current free-learning round.
**Architecture:** IndexedDB v9 adds ModuleProgress and immutable ModuleRun. Each progress record uses exam/module identity, a generation plus unique run ID, explicit question states and source attempt IDs. Generation1 captures eligible legacy attempt IDs without mutating them. Reset atomically creates a new run and clears only scoped drafts; new attempts/drafts must match the current run. Deletion falls back within that run only. Notes migrate before any old draft/attempt can be removed.
**Stack:** React, TypeScript, Dexie, existing offline sync/CAS contracts and static GitHub Pages.
