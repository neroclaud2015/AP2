Google 账号同步：Firebase 设置

代码与本地模拟器测试已完成。尚未配置或部署真实 Firebase 项目，不能声称真实两设备云同步已经通过。

  1. 在 Firebase Console 创建项目；Analytics 不是必需。
  2. Authentication → Sign-in method 启用 Google，设置支持邮箱。Authorized domains 加入 neroclaud2015.github.io，开发时另加 localhost。
  3. 创建 Cloud Firestore，选择区域与生产模式。不要采用公开读写的测试规则。
  4. Rules 页面粘贴仓库完整 firestore.rules 并发布；同时应用 firestore.indexes.json。
  5. Project settings → Your apps → Web App（</>）→ Config 获取 Web 配置，无需 Firebase Hosting。
  6. 填写 VITE_FIREBASE_API_KEY、VITE_FIREBASE_AUTH_DOMAIN、VITE_FIREBASE_PROJECT_ID、VITE_FIREBASE_APP_ID；senderId/storageBucket 可选。仅这些公开 Web 配置进入前端构建。
  7. 重新构建后，Windows 与 Android/iPad 用同一 Google 账号登录，明确确认本地迁移，再验证双向同步、离线恢复、重复重试与冲突。

绝不提供或提交：服务账号 JSON/私钥、Admin SDK 凭据、OAuth client secret、服务器管理员 key、用户 token 或学习备份。

IndexedDB 始终支持离线学习。Firestore 用 uid 私有路径、事务版本、tombstone、幂等收据和明确冲突；不上传题库。模拟器结果不等于真实云验收。
