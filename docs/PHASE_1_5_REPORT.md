# Phase 1.5 验收报告

范围严格限定：**2017 Sommer Arbeitsplanung，13 个物理 PDF 页**。没有重新处理 Funktionsanalyse、WiSo、答案 PDF，也没有打开其他年份 ZIP。

## 结果

- 自动识别 **36 题**：选择题 1–28，U1–U8。数量与原卷说明页中 28 + 8 的要求一致，无缺号、重复号或意外题号。
- **32 题 auto_ready**，可以直接逐题浏览，不要求逐题确认或重新录入。
- **4 题 Needs Review**：8（题号只由 OCR 识别），24、25、27（L 形或分开的原题/计算区）。
- `auto_ready` 是版面规则满足阈值，不等于官方答案已确认，也不是校准后的统计概率。
- 图片从原 PDF 以 180 DPI 渲染。多区域题按原坐标合成并将邻题区域留白，保留图纸、表格、公式和原版字体。
- 每题保存稳定来源 ID、考试/模块/题号、PDF/页码、外接框、多区域坐标、裁剪图、辅助文字、版面置信度、版本和复核原因。

## Review/Edit

默认页面为逐题图像浏览；整页文字只保留在 Review/Debug。支持修改题号、拖动重框或输入裁剪坐标、修改辅助文字、编辑个人知识点标签、选择/确认答案 PDF 页、标记 Confirmed / Needs Review。

修改通过 IndexedDB 原子保存，覆盖显示层而不改动机器生成数据。刷新后仍在；机器更新不会覆盖。支持备份导出/导入。编辑中禁用导入，避免旧草稿覆盖新导入的数据。

答案关联确认与题目裁剪确认分开。当前没有自动确认官方答案；选择答案页是来源关联，不是自动评分。个人标签不会悄悄扩充全局知识体系。

## 版本与断点

- 原 ingestion v1 manifest、原始提取页、原始 PDF/整页图完全保留。
- 新 manifest：`data/ingest/segmentation_manifest.json`。
- 有效版本：`1.5.3-b83cba55b70e`。处理键包含指定文档的 SHA-256、segmenter 版本和布局配置哈希。
- 新版本只对显式指定的文档生效；当前命令只允许 Arbeitsplanung 的文档 ID，不提供全量参数。
- 每页原子保存题目记录与裁剪，再保存 checkpoint。完成的同版本页直接复用。
- 题目 ID 基于 PDF 物理页和题号锚点位置，独立于可变 OCR 题号。以后修改锚点拓扑需要显式迁移，不能仅换版本后丢弃人工编辑。
- 最终版实测：先处理 4 页暂停，恢复只处理余下 9 页；第三次处理 0 页，13 个页记录修改时间不变；测试禁止重新打开 PDF，仍然通过。

运行：

```sh
python scripts/segment.py --document 35c77ffdb630f70057e4cfb8 --max-pages 4
```

若原始文件哈希改变，先显式迁移不可变来源。不得自动重扫整个档案。

## 仍不能可靠自动处理的情况

1. 当前布局规则只验证了这份左右拼版、三带式试卷；不同年份/模块、明显倾斜、跨页续题不能直接沿用。
2. 反白/损坏题号和 L 形区域仍可能有歧义，因此上述 4 题保留 Review。
3. 德文 text layer 仍有字符错误。文字仅用于辅助搜索和理解，不作为唯一事实来源，不承诺公式 OCR 正确。
4. 手动拖框会建立一个新矩形；复杂题默认保留自动多区域遮罩，也可恢复自动裁剪。复杂多区域的自由多边形编辑尚未实现。
5. U 题共同附件不是自动合成到每题图片中；通过“共同资料”原 PDF 链接核对。
6. 官方答案的精细逐题/子题关联和评分没有自动确认；目前可人工选择并确认答案出处页。
